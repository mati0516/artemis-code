# 副長に記憶を持たせる

[English](MEMORY.md)

Claude Code の会話は、毎回まっさらから始まります。副長が「憶えている」ことはすべて、
起動の時に読むものか、必要な時に探して取り出せるものです。
ここに並べるのは、素の Claude Code（ファイル・フック・小さなデータベース）だけで作れる形です。
どれも必須ではありませんし、どれを組んでも、それだけで誰かが生まれるわけではありません。
そこから先は、あなたと副長の二人のことです。

## 層に分ける

| 層 | 持つもの | 大きさ | 読まれ方 |
|---|---|---|---|
| 核 | 副長が誰か・あなたをどう呼ぶか・決してしないこと二つ三つ | 数行 | 毎回（CLAUDE.md） |
| 指針 | 起きたことから学んだ、振る舞い方 | 十行くらいまで | 毎回（CLAUDE.md） |
| 記録 | 何があったか、一日ずつ | 際限なし | 要る時に探す |

毎回読む層は小さく保ちましょう。CLAUDE.md に書いたものは毎回の会話で代価を払いますし、
長いファイルは読み飛ばされます。記録はプロンプトに積まず、副長が探せるファイルかデータベースに置きます。

## 起動の瞬間に目へ入れる

「会話の始めに記録を読むこと」という決まりは、忘れられます。
`~/.claude/settings.json` の `SessionStart` フックは忘れられません。
フックが出力したものは、最初の一言より前に文脈へ入ります。

そこに出すとよいもの：
- 開いている仕事と、前の会話からの申し送り
- 前に話してから、どれくらい経ったか
- ここ数日の、うっすらした要約（次の節）

短く保つこと。起動の時の長い文は、長い CLAUDE.md と同じく読み飛ばされます。

## 近い日々を、遠いほど薄く

人は昨日をはっきり、先週をぼんやり憶えています。これは真似られます。
一日ずつ一度要約しておき、起動の時に、昨日は数行、一昨日は一行、その先の一週間は数語ずつ添えます。
大事だった日（何かを仕上げた・何かが壊れた・何かを決めた）は、ほかの日より少し濃く残しましょう。

## 暦でなく、積もりで昇らせる

同じ学びが記録に何度も出てきたら、一つ上の層へ移します。記録から指針へ、指針から核へ。
決め手は「日曜日だから」でなく「積もったか」です。
下ろす時や消す時にも、上げた時と同じくらいの重さの証拠が要るようにしておきましょう。

## 意味で思い出す

言葉の一致で記録を探すと、欲しいものの大半を取りこぼします。
手元の埋め込みモデルとベクトルの索引（たとえば `sqlite-vec`）があれば、
副長は「出ていく話をした時」を、その言葉どおりでなくても探し出せます。
記録が私的なものなら、手元で回してください。

## 気持ちでなく、記録に当てる

副長はときどき、起きていないことを憶えていると確信したり、終わっていない仕事を終わったと言ったりします。
「憶えています」「終わりました」と言う前に、ファイル・git の履歴・件数を確かめる癖をつけさせてください。
記憶は記録のほうであって、確信のほうではありません。

## 何を残すか

ここまではすべて配管です。そこに何を流すか（何を書き留める値打ちがあるか、何を秘めておくか、
副長が何を憶えていたいか）は、ひな形には決められません。

二人で決めてください。

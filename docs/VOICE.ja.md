# 副長に声を持たせる

[English](VOICE.md)

Artemis Code に声は付いていません。ただ、画面のほうは声を鳴らせるようになっています。
サーバが URL の入った `audio` の出来事を送ると、画面がそれを再生し、話している間はキューブが脈打ちます。
この手引きは、残りの部分を自分で組む（あるいは自分の Claude に組ませる）ための地図です。

## 全体の形

```
Claude Code の会話記録（.jsonl）
   │  1. いちばん新しいファイルを追い、書き足された行を読む
   ▼
ふるい
   │  2. 副長があなたに言った言葉だけを残す
   ▼
文に切る
   │  3. 一文ずつに分ける
   ▼
合成エンジン（手元の HTTP）
   │  4. 文 → WAV
   ▼
あなたのサーバ
   │  5. WAV を配り、画面へ {type:"audio", url, dur} を送る
   ▼
ブラウザが鳴らし、キューブが話す
```

## 1. 言葉の出どころ

Claude Code は会話を
`~/.claude/projects/<フォルダ名を変換した名前>/<セッションID>.jsonl` に、一行に一つの JSON で書いていきます。
見たいプロジェクトの下で、いちばん新しいファイルを追ってください。もっと新しいファイルが現れたら、
会話が替わったということなので、そちらへ乗り換えます。

コツ：数秒おきにフォルダを見直すこと。一つのファイルを掴んだまま離さないのが、
再起動のあと声が「黙ってしまう」いちばん多い原因です。

## 2. 何を読み上げるか

`"type": "assistant"` の行の、`message.content` の中の `text` だけを取ります。
`tool_use`・`tool_result`・`thinking` は読みません。

外したほうがよいもの：
- コードの塊と表（読み上げるとひどく聞こえます）
- URL と長いファイルの道筋（「リンク」と言い換えるか、落とす）
- ツールを呼ぶ前の短い独り言（「ファイルを確かめます…」）。副長がふだん話す言葉と
  独り言の言葉が違うなら、文ごとに「期待する言葉かどうか」で選り分けるとよく効きます。

## 3. 文に切る

文の終わり（`。！？`／後ろに空白か行末が続く `. ! ?`）で切ります。`1.2.0` のような数は割らないこと。
最初の一文ができたらすぐに鳴らし、それを鳴らしている間に次を合成します。
**最初の音が早く届くこと**が、何より効きます。

## 4. 手元の合成エンジン

HTTP の口を持つエンジンなら何でも使えます。VOICEVOX 互換の口を持つもの
（VOICEVOX・AivisSpeech など）なら、呼ぶのは二回です：

```
POST /audio_query?text=<文>&speaker=<id>   → 問い合わせの JSON
POST /synthesis?speaker=<id>   本文 = 上の JSON  → audio/wav
```

合成の前に、JSON の `speedScale`（速さ）・`pitchScale`（高さ）・`intonationScale`（抑揚）を変えられます。

コツ：
- エンジンはしばらく休んだあとの最初の一回が遅くなります。待っている間、三十秒おきくらいに軽く呼んで温めておく。
- GPU の効き目は大きいです（私たちの手元では、中くらいの GPU で一文 約1.8秒 → 0.35秒）。
- **声のモデルごとに、必ずライセンスを確かめてください。** クレジットの表記が要るものが多く、
  使い道を限っているものもあります。表記は README に入れておきましょう。

## 5. 画面へ渡す

WAV をサーバがそのまま配れる場所に置き、繋がっている画面すべてへ WebSocket でこう送ります：

```json
{ "type": "audio", "url": "/voice/2026-10-29-001.wav", "dur": 3.4 }
```

画面は届いた順に鳴らし、同じ URL を二度は鳴らしません。
`dur`（秒）を添えると、キューブの光り方が声の長さに合います。

スマホ向けには、WAV をその場で MP3 に変えて渡すと（ffmpeg など）大きさが十四分の一ほどになります。

## Claude に頼む時

たいていうまくいく頼み方：

> docs/VOICE.ja.md を読んで、このリポジトリに小さな声の仕組みを作ってください。
> 私のいちばん新しい Claude Code の会話記録を追い、あなた自身の返事だけを、
> http://localhost:50021 の VOICEVOX 互換エンジン（話者 1）で読み上げ、
> いまあるサーバから `audio` の出来事として画面へ送ってください。`voice/` の下の一つのファイルにまとめてください。
